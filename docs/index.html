Что умеет

Любой плеер

Yandex Music, Spotify, Music, браузер — берёт системный «Сейчас играет».

Управление

Кнопки ⏮ ⏯ ⏭ работают через системные медиаклавиши.

Время и батарея

Раскрытый остров показывает время и заряд с индикатором зарядки.

Не мешает

Поверх всех окон и столов, клики вокруг проходят насквозь. Живёт в строке меню.

Установка

Нужны macOS 14+ и Xcode Command Line Tools (xcode-select --install).

git clone https://github.com/vmaiorov-collab/NotchIsland.git
cd NotchIsland
./build.sh
open NotchIsland.app
  1. Если macOS не открывает приложение — правый клик → «Открыть».
  2. Чтобы запускалось само, включите «Запускать при входе» в меню капсулы в строке меню.

Важно знать

Чтение «Сейчас играет» и закрепление окна используют приватные API macOS (MediaRemote и SkyLight). Они могут перестать работать после обновления системы. На Mac без чёлки остров рисуется как плашка по центру сверху.
