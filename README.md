# NotchIsland

Превращает чёлку MacBook в Dynamic Island. При наведении остров раскрывается и показывает время, заряд батареи и текущий трек с кнопками управления.

Сайт: https://vmaiorov-collab.github.io/NotchIsland/

## Возможности

- Любой плеер: Yandex Music, Spotify, Music, браузер (системный «Сейчас играет»)
- Кнопки ⏮ ⏯ ⏭ через системные медиаклавиши
- Время и заряд батареи
- Пружинная анимация, эквалайзер по бокам чёлки при воспроизведении
- Иконка в строке меню: «Запускать при входе», «Выйти»

## Сборка

Нужны macOS 14+ и Xcode Command Line Tools.

```sh
./build.sh
open NotchIsland.app
```

## Как это устроено

- Now Playing читается через приватный MediaRemote, загруженный внутри `/usr/bin/perl` (на macOS 15.4+ прямой доступ закрыт).
- Окно закрепляется через приватный SkyLight, чтобы не двигаться при смене рабочих столов.
- Эти приватные API могут сломаться в будущих версиях macOS.
